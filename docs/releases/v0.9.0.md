## Highlights

- Adaptive processing is now the default. Babel analyzes each uploaded source and chooses safer batch size, concurrency, timeout, retry, and fallback settings automatically.
- Advanced processing controls remain available in Settings for users who need manual overrides.
- Large and slow books are more resilient: uploads stream to disk, preparation runs asynchronously, oversized paragraphs can be split, and failed batches can fall back to smaller requests.
- Diagnostics now distinguish source-file, environment, API, and Babel failures and provide practical recovery guidance across supported formats.
- A P0 task-start race was fixed so duplicate requests cannot mark an active translation as failed while its worker continues writing output.
- Temporary uploads are cleaned up if the handoff into a job workspace fails.
