# Babel v0.2.0

## Added

- Self-hosted Web UI via `babel-server`.
- Docker and Docker Compose deployment.
- Local job engine for upload, glossary review, provider execution, progress, downloads, audit, and reports.
- OpenAI-compatible, Anthropic Claude, and fake dry-run provider adapters.
- Claude Desktop MCP server via `babel-mcp`.
- Codex skill integration under `integrations/codex/babel`.
- Tests for job execution, provider response parsing, Web shell rendering, and multipart upload parsing.

## Notes

- MVP is single-user self-hosted. Do not expose the Web server publicly without adding authentication.
- EPUB files, JSONL batches, generated workspaces, and translated outputs are intentionally ignored by git.
