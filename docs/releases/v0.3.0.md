# Babel v0.3.0

## Added

- Multi-format ebook input support.
- Native internal conversion for plain text and HTML inputs.
- Calibre-backed conversion for mainstream ebook/document formats:
  `.mobi`, `.azw`, `.azw3`, `.kfx`, `.pdf`, `.fb2`, `.docx`, `.rtf`, `.cbz`, `.cbr`, and related formats.
- Input format metadata written to `pipeline/input_format.json`.
- Web upload field now accepts supported ebook extensions.
- Docker image installs Calibre so self-hosted users get conversion-backed formats out of the box.

## Notes

- Babel still normalizes inputs to EPUB internally and produces EPUB output.
- EPUB remains the highest-fidelity path because Babel can operate directly on existing XHTML structure.
- TXT/HTML use Babel's built-in converter.
- Kindle/PDF/Office/comic formats require Calibre `ebook-convert`; the Docker image includes it, while source installs need Calibre installed separately.
