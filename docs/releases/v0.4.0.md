# Babel v0.4.0

## Added

- User-selectable final output formats across CLI, Web UI, job engine, and Claude MCP.
- Supported output formats: `.epub`, `.mobi`, `.azw3`, `.pdf`, `.docx`, `.txt`, `.html`, `.htmlz`, `.kepub`, `.rtf`, and `.fb2`.
- Output conversion metadata written to `pipeline/output_format.json`.
- Web UI output format selector and generic translated-book download link.

## Changed

- `babel-epub apply` now prefers `--output-book` and keeps `--output-epub` as a deprecated compatibility alias.
- `babel-epub report` now records the selected final output file and conversion method.
- EPUB remains the internal translation and audit format; non-EPUB outputs are exported from the validated EPUB intermediate.

## Notes

- EPUB output does not need external tools.
- Non-EPUB output requires Calibre `ebook-convert`; the Docker image includes it, while source installs need Calibre installed separately.
- Babel rejects missing or mismatched output suffixes such as `--output-format pdf --output-book output.epub`.
